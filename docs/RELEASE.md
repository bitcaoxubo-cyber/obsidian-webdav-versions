# 0.4.0-beta.2：手机删除后的空目录清理

手机接收 Mac 的文件删除或移动后，旧版已删去文件，但会留下原来的空目录。本版补上受限的空目录清理，保留有内容或仍受保护的目录。

## 变化

- 手机接收或确认文件删除后，检查旧路径的相关父目录，仅用非递归操作删除当时确认完全为空的目录。
- 更新后的手动全量同步、首次启动或回到前台的全量轮，会检查旧版遗留的相关空目录。
- 候选路径必须有有效的远端纯删除记录，且本地已确认文件不存在。远端仍有存活文件、冲突或待处理后代的目录保留；含本地文件、隐藏项目或任意子文件夹的目录也保留。
- 不清理无关空树、笔记库根目录或配置目录。文件内容校验、并发修改保护、日志恢复、远端协议和历史记录保持原有语义。
- 文件夹本身不单独同步，从未有过同步文件的空目录不参与清理。有删除历史的同一路径后来重建为空目录，仍符合清理条件时，后续全量同步会再次整理。

## 升级影响

只需更新手机插件，Mac 可继续使用 `0.4.0-beta.1`。保留现有设置、笔记和 `local-state/`，不需要清空状态或重建库。手机更新后保持前台，手动运行一次“立即同步”，检查已删除路径对应的旧空目录。

从 `0.3.0-beta.1` 升级时仍可读取原本地状态和未完成 pending；v2 布局仍要求所有客户端至少为 `0.3.0-beta.1`，没有自动迁移。

中断后不能直接降级到 `0.3.0-beta.1`：该版本不理解新独立日志。先备份完整库含 `local-state/`，用新版本成功完成手动全量同步，确认无错误、待处理为 0、pending 为空、完成收据已入检查点，再停用插件降级。无法恢复时保留现场与未同步笔记，不得删除状态绕过检查。

## 验证与边界

用户已在手机实际使用 `0.4.0-beta.1`，并确认原问题为空文件夹残留。**0.4.0-beta.2 的空目录清理尚未完成 iPhone 真机验收。** 真实试用不等于本版全部验收项通过；新清理行为须在独立测试库验证，尤其检查隐藏文件、子文件夹、冲突和待处理路径均被保留。

本版 243 项自动测试全部通过，保留原 232 项并新增 11 项，覆盖删除、移出、目录重命名、历史残留补清、受保护目录保留、清理中断恢复及后续下载重建目录。移动端打包测试还验证了无 Node 环境的清理和状态界面。v1/v2 阶段B阈值及规模翻倍检查通过，普通无删除场景的基准操作次数和字节数与前版一致。

前版的 232 项测试和性能数据仍作为 [0.4.0-beta.1 历史性能报告](https://github.com/bitcaoxubo-cyber/obsidian-webdav-versions/blob/0.4.0-beta.1/docs/perf/%E6%80%A7%E8%83%BD%E4%BC%98%E5%8C%96%E6%8A%A5%E5%91%8A.md) 的记录，不代表新增清理行为已通过手机真机验收；前版发布说明见 [0.4.0-beta.1](https://github.com/bitcaoxubo-cyber/obsidian-webdav-versions/releases/tag/0.4.0-beta.1)。

本次开发验证不对真实 WebDAV 做写入。空目录清理只作用于手机本地目录，不清理远端历史。手机单文件上限仍为 128 MiB，桌面为 512 MiB；未增加后台同步、端到端加密或历史清理。

## 安装

更新现有手机插件时保留 `data.json` 和 `local-state/`，只替换插件程序文件；先备份，先在独立测试库验收。

在 BRAT 添加 `bitcaoxubo-cyber/obsidian-webdav-versions`，选择固定 Release 版本 `0.4.0-beta.2`；也可下载同版本 zip 手动安装。步骤见 [iPhone 安装与验收](https://github.com/bitcaoxubo-cyber/obsidian-webdav-versions/blob/main/docs/iPhone%E5%AE%89%E8%A3%85%E4%B8%8E%E9%AA%8C%E6%94%B6.md)，验收期间不要自动跟随最新版本。
