# 0.3.0-beta.1：修复 WebDAV 大目录枚举上限

部分 WebDAV 服务在同一目录中有大量对象时，只返回前 10000 项，却仍给出成功状态及完整 XML。旧版会把未列出的历史记录判断为缺失而暂停。新版明确提示该边界，并增加分目录存储。

## 变化

- 支持 `obsidian-webdav-versions-v2/`，按 SHA-256 首字符分成 16 个目录，逐个枚举并校验。
- 小型旧库仍可使用 v1。大库需显式迁移；插件启动或更新不会自动迁移远端。
- 迁移逐批移出旧目录对象，使被截断的后续对象变为可见；每个对象移动后读回校验，版本记录可额外保存本机备份。
- 迁移、继续迁移和回退均不发送远端 DELETE；重复对象及布局元数据归档保留。
- 修订 ID、父版本关系、内容哈希和本地同步状态保持不变。真正缺失、内容损坏、旧设备继续写入或迁移未完成时仍暂停。
- 原有手机本地库、SecretStorage、前台同步及大附件分段下载功能保留。无需 iCloud。

## 升级影响

**迁移到 v2 后，每台 Mac 和 iPhone 都必须更新到 0.3.0-beta.1 或更新版本。0.1.1 / 0.2.0-beta.1 无法识别 v2，会停止同步。**

迁移前暂停其他设备，在独立目录验证服务器 MOVE、读取、冲突保留及回退，再迁移正式库。不得清空 local-state 来绕过版本缺失检查。

## 验证与边界

61 项自动化测试通过，涵盖 10000 项截断、逐批迁移、断点恢复、校验失败停止、真实缺失版本、旧客户端残留写入、逐字节回退，以及原有桌面和模拟移动环境回归。

iPhone 真机仍待验收。手机单文件 128 MiB，桌面 512 MiB；手机仍需要一个完整文件的内存空间。原生 requestUrl 要求使用可信且不跳转的最终 HTTPS 地址。没有端到端加密或锁屏持续同步。

## 安装

BRAT 添加 `bitcaoxubo-cyber/obsidian-webdav-versions`，固定 `0.3.0-beta.1`。iPhone 新库关闭 Store in iCloud。先完成 [安装与验收](iPhone安装与验收.md)，迁移见 [布局说明](存储布局迁移.md)。
