# 0.4.0-beta.1：移动端同步性能优化

空闲同步复用文件哈希与已验证修订，日常编辑采用增量路径；批量同步改用小日志、检查点和四路传输。远端协议及 v1/v2 布局不变。

## 变化

- 稳态空闲轮不读取库内文件、不写状态快照；近期 2 秒文件仍重读，防止时间戳竞争。
- 文件、blob 和状态内容优先使用异步 WebCrypto，缺失时保留同步 SHA-256 回退。
- 手机文件变更防抖为 15 秒，桌面为 5 秒；空闲轮询由 60 秒逐步延长至 300 秒。
- 修复持续待处理文件反复触发防抖同步的问题：待处理重试按60→120→240→300秒退避；有新文件事件时仍按手机15秒、桌面5秒防抖重试。
- 首次加载、回到前台、手动同步、解决冲突、错误后及每 10 分钟做全量检查。外部无事件修改等下一次全量轮才会发现。
- 新增“深度校验同步”，忽略文件哈希缓存。状态面板显示本轮类型、耗时、读取、哈希、HTTP 请求数及轮询间隔。
- pending、完成收据与主检查点协作恢复；完成收据保留检查点尚未记录的真实文件绑定，避免远端继续推进后的重复修订。
- 传输最多 4 路；按手机 32 MiB、桌面 128 MiB 的 payload 预算分批，单个大文件独占通道。修订发布、日志和本地 CAS 落盘保持串行。

## 升级影响

可直接读取 `0.3.0-beta.1` 的本地状态和未完成 pending，无需清空 `local-state/`。新增缓存、独立 pending、完成收据及检查点水位均只保存在本机；修订 JSON 字段、ID、对象名、远端目录及 blob 字节不变。

同一受支持布局可与旧版本客户端混用。v2 仍要求各端至少为 `0.3.0-beta.1`，没有自动迁移。

中断后不能直接降级：旧版本不理解新独立日志。先备份完整库含 `local-state/`，用新版本成功完成手动全量同步，确认无错误、待处理为 0、pending 为空、完成收据已入检查点，再停用插件降级。无法恢复时保留现场与未同步笔记，不得删除状态绕过检查。

## 验证与边界

208 项自动测试通过，保留原 61 项断言及 0.1.1 协议夹具。新增测试覆盖缓存、WebCrypto 回退、增量与假时钟调度、过期清单并发写入、所有指定中断点、远端继续推进及双重崩溃、共享附件预检预约、四路传输和大小预算。构建产物与源码一致。

模拟移动路径的 1000 篇笔记加 10 个 1 MiB 附件中，空闲库内读取和同步 JS 哈希均为 0；改一篇笔记的增量轮为 71 次适配器调用，规模翻倍不变。首次下载哈希量为库大小的约 7.51 倍。冷启动上传 HTTP 总数含初始化开销：v1 为 5059、v2 为 5102，任务发布者在补充任务C2中将阈值修正为每新增文件的边际请求数。1010/2020文件差分下两布局均为5.000次/文件，固定开销分别为9/52次，原始总数完整保留；其他阈值未改，复测全部通过。原始结果、延迟对照和完整限制见 [性能优化报告](perf/性能优化报告.md)。

**iPhone 真机尚未验收，未在真实 WebDAV 上写入验证。** 输入流畅性、机身发热、实际内存和前后台恢复仍需独立测试库验收。预算约束传输 payload，不能视为 WebView 总内存上限；原生整包缓冲、状态暂存和哈希可能有额外瞬时分配。手机单文件上限仍为 128 MiB，桌面为 512 MiB。

大附件上传后的完整回读与 SHA 校验仍保留；未实施 B2b、B5b、后台同步、端到端加密或历史清理。检查点在测试规模下接近线性，但完整快照仍有随规模增长的残余成本。

## 安装

本次交付为 `perf/mobile-sync` 评审分支和本地安装包，**未打 tag、未发布 Release**；BRAT 目前不能选择这个尚未发布的版本。

执行 `node scripts/build.js && node scripts/package.js` 后，将 `dist/obsidian-webdav-versions-0.4.0-beta.1.zip` 中的插件目录安装到独立测试库 `.obsidian/plugins/`。维护者另行发布测试版后，手机可按 [iPhone 安装与验收](iPhone安装与验收.md) 使用 BRAT 固定版本。先验收，再考虑正式库。
