# NAS 无头同步端：当前任务说明

本文件补充用户提供的《补充任务书（五）：NAS 无头同步端》，记录实施中获用户批准的 H9 修订。原附件保持原样；本文件不替代原任务书的其他要求。

## 目标与交付

基于 `main` 的 `bdb26b7`，为 NAS 增加独立于 Obsidian 的无头同步端：Muse 通过 WebDAV 操作普通 `vault/` 文件夹，同步端复用现有引擎，与 Mac 和 iPhone 交换版本并保留冲突内容。实现 G1 入口、配置与循环，G2 稳定扫描、删除闸门和文件名检查，以及 G3 Docker 和部署文档。

在新分支完成实现、测试和验收报告，提交 PR 后停下等待评审。本轮不发布插件版本、不推送 Docker 镜像、不部署到真实 NAS。

## 已获批准的 H9 修订

原要求是：其他设备的新版本到达时，外部工具刚修改的内容仍须位于 `vault/` 的原路径。

当前要求是：**外部内容不丢失，可保留于原路径或冲突副本。** 用户已同意保持引擎和协议不变，按此要求更新验收并继续提交 PR。

修订的原因是原引擎按版本 ID 排序分配原路径和冲突副本，ID 又含随机 nonce；双方内容会保留，但外部内容的位置并不固定。原模型的复现记录及代码依据见 [H9 修订与基线证据](NAS无头同步端-H9修订.md)。

H9 仍应复现“同步开始前两端已经各自修改”的原场景，并检查完整外部正文及其对应路径。扫描后才发生的新写入保护属于独立时序，不能用于替代该场景。

## 其余约束保持不变

- `src/` 只允许为 `DiskVault` 增加可选的外部私有目录参数；不传参数时保持原行为。引擎、协议、WebDAV、分片布局、移动端、插件入口和调度器均不修改。
- 既有 414 个测试不修改、不移除；新测试位于 `test/headless-*.test.js`。重新生成 `main.js`，无头端代码不进入插件 bundle 或发布包。
- 不新增依赖，不修改 `manifest.json`、`versions.json`。测试仅使用临时目录、内存模型或本机回环地址的假 WebDAV，不连接真实服务。
- 无头端不自行处理冲突、待确认项或布局迁移；除现有引擎本身的操作外，不替用户修改、移动或删除笔记。
- 逐项记录 H1–H32 的实际结果，保留基准输出与已知限制；未运行或未通过的项目不能写成通过。真实飞牛、Muse、Mac/iPhone 和 24 小时运行项目另列待验收清单。
- 如果出现新的原任务书停止条件，仍需停下说明；本次授权只解除已明确修订的 H9 阻断。

操作方式见[部署说明](NAS无头同步端.md)，供 Muse 使用的规则见[外部编辑约定](外部编辑约定.md)，最终验证情况以[验收报告](NAS无头同步端-验收报告.md)为准。
