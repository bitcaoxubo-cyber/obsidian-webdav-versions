# iPhone 安装与验收（不使用 iCloud）

本文件适用于 `0.4.0-beta.1` 的验收。该评审分支尚未发布 Release，下面的 BRAT 固定版本安装步骤须等维护者另行发布测试版后执行；当前交付提供手动安装包。自动化测试和模拟移动环境不等于 iPhone 真机验收。

## 安装插件

1. 更新 iPhone 上的 Obsidian，至少为 1.11.4。
2. 新建空白测试库，例如“飞牛手机测试”；**关闭 Store in iCloud / 保存到 iCloud**。在“文件”App 中确认位于“我的 iPhone → Obsidian → 飞牛手机测试”。
3. 设置 → 第三方插件 → 启用第三方插件。浏览社区插件，搜索 **BRAT**，安装并启用。
4. 打开 BRAT 设置或命令面板的添加测试插件命令。仓库输入：
   `https://github.com/bitcaoxubo-cyber/obsidian-webdav-versions`
5. 待发布后，选择固定 Release 版本 `0.4.0-beta.1`。首次验收期间不要自动跟随最新版本。
6. 在第三方插件列表启用 **WebDAV Versions · 飞牛同步**。无需在手机安装 Node、Git 或复制隐藏文件夹。

公开仓库安装无需 GitHub Token。GitHub 只用于安装和更新插件，日常笔记同步走飞牛。

## 远端布局兼容

若正式远端已迁移为 v2，手机及每台 Mac 都须使用 0.3.0-beta.1 或更新版。先更新全部设备，再恢复同步。0.1.1 和 0.2.0-beta.1 不支持 v2；勿删除本机同步状态绕过提示。

## 独立测试配置

1. 在飞牛现有 WebDAV 目录下创建独立测试子目录。Mac 另开一个空白测试库，与手机测试库使用这个子目录；不要拿正式笔记做删除和冲突实验。
2. 手机填写该子目录的完整 HTTPS 地址、用户名和设备名 `iPhone`。Mac 测试库设备名填 `Mac-Test`。
3. 在各自设备通过密钥选择器输入密码。不要复制其他设备的 `data.json`、`local-state`、待上传内容或密钥。
4. **自动同步保持关闭**。先测试连接、保存设置，再手动“立即同步”。连接测试只证明目录可读，上传测试才证明写权限。
5. 手机设置页有“立即同步”“查看详情”；命令面板提供“立即同步”“查看同步状态”“深度校验同步”“查看同步冲突”。

## 真机验收表

每项完成后记录日期、iPhone 型号、iOS / Obsidian 版本及结果。当前未填写的项目均为待验收。

|---|---|---|
| 安装启动 | BRAT 可安装固定版本；启用后设置页可打开，无加载错误 | 待验收 |
| Mac → 手机 | Mac 新建中文 Markdown、图片、PDF，先 Mac 后手机同步；手机列表可见、链接及文件可打开 | 待验收 |
| 手机 → Mac | 手机编辑并新增笔记，同步后 Mac 内容一致 | 待验收 |
| 断网编辑 | 手机离线保存，重连后同步；内容可在 Mac 读取 | 待验收 |
| 并发编辑 | 两端从同一正文离线修改不同内容，再依次同步；两端保留两份完整内容 | 待验收 |
| 冲突解决 | 比较双方，采用指定版本；另一端同步后内容一致 | 待验收 |
| 后台 / 重启 | 同步中切后台或退出，重新进入后手动同步；文件完整，不出现把未完成下载当作删除的情况 | 待验收 |
| 本地编辑保护 | 同步下载时编辑正文；本机新内容保留或提示下轮处理 | 待验收 |
| 重命名 / 删除 | 只操作测试文件，两端最终一致；删除与修改并发时保留修改 | 待验收 |
| 大附件 | 从小 PDF 逐步到实际使用的最大附件；两端 SHA-256 一致，手机能打开，不闪退 | 待验收 |

## 接入正式笔记库

1. 先完成上述真机测试，并保留正式库的独立备份。
2. 在 iPhone 建立新的**空白本地正式库**，同样关闭 Store in iCloud，安装固定版本插件。
3. 填入 Mac 正式库使用的同一个 WebDAV 目录，设备名设为 `iPhone`，手机独立保存密码。
4. 关闭自动同步，手动首次同步。远端版本目录由插件解析，不能把 NAS 对象目录直接拷贝成笔记库。
5. 保持应用在前台，使用稳定 Wi-Fi、接电；确保手机有完整笔记库及临时工作空间所需容量。128 MiB 为单文件上限，非整库上限。
6. 检查笔记、图片和 PDF，核对可见文件数量及内容哈希。版本记录数量不等于文件数量；待处理项应为 0，冲突需逐一比较。
7. 验收完成后开启自动同步。打开后先等同步，编辑完等“已同步”再离开应用。

同步只在 Obsidian 前台运行；不会承诺锁屏持续同步。这个流程不依赖 iCloud Drive，也不要求购买 Obsidian Sync。

## 故障与回退

- 手机提示同步暂停时，先保留本地库和错误信息。不要直接删除 `local-state`，其中可能有离线待上传内容。
- 若测试版不适用，关闭手机插件及自动同步，继续使用原有 Mac 版。先导出手机尚未上传的笔记，再考虑卸载。
- `0.1.1` 是桌面版，不能作为手机回退版本。后续手机版本回退需选择此前通过真机验收的移动端 Release。
- 更新移动版前备份本地库。BRAT 固定版本可防止未验证版本自动替换。
